# Song-Logos (nur für AnMaCha Beat Surfer)

Es gibt **13 Songs**. Song *n* bekommt das Logo mit der Nummer *n*: `01` … `13`, als `.png`, `.jpg` oder `.jpeg` (Endungen dürfen gemischt sein).
Jedes Spiel hat seinen eigenen Ordner – die Bilder der anderen Spiele sind davon getrennt.

- Das Logo erscheint als große Tafel hinter der Bahn und in der Songauswahl
- Fehlt ein Logo, zeigt der Song einen Platzhalter mit der Nummer
- Tipp: ca. 400 × 400 px, unter 200 KB, damit das Spiel schnell lädt
- Bei file:// blockiert der Browser die Bilder: Spiel über GitHub Pages oder einen lokalen Server öffnen
- Titel-Logo des Spiels: `anmacha-beat-surfer/logo.png` (eine Ebene höher)
