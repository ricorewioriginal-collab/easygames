# Hindernis-Bilder

Hier die Bilder für die Hindernisse ablegen, benannt `01.png`, `02.png` … bis `20.png`
(13 Senderlogos + bis zu 7 weitere Elemente wie Mikrofon, CD, Schallplatte).

- Format: PNG, quadratisch oder quer, mindestens 256 px, transparenter Hintergrund erlaubt
- Es werden nur vorhandene Dateien genutzt; Lücken in der Nummerierung sind okay
- Ohne Bilder startet das Spiel automatisch mit Platzhalter-Hindernissen
