# Drittanbieter-Software

RIFTZONE verwendet **keine fremden Assets**: Insel, Gebäude, Figuren, Waffen, Fahrzeuge, Texturen, Klänge und Musik
sind eigene Arbeiten und werden im Code erzeugt.

| Paket | Version | Lizenz | Verwendung |
| --- | --- | --- | --- |
| three | 0.180.0 | MIT | 3D-Darstellung (WebGL 2), `BufferGeometryUtils` |
| ws | 8.21.3 | MIT | WebSocket-Server |
| vite | 7.1.12 | MIT | Entwicklung und Build |
| esbuild | 0.28.2 | MIT | alternativer Build, Server-Bündel |
| typescript | 6.0.3 | Apache-2.0 | Programmiersprache und Typprüfung |
| tsx | 4.19.2 | MIT | Tests und Server im Entwicklungsmodus |
| playwright | 1.56.1 | Apache-2.0 | Browser-Tests |
| @types/three, @types/node | – | MIT | Typdefinitionen |

RIFTZONE ist ein unabhängiges Spiel mit eigener Marke. Es nutzt nur allgemeine Spielmechaniken des
Battle-Royale-Genres und enthält keine Inhalte, Namen, Figuren, Karten, Klänge oder Oberflächen anderer Spiele.
