# RicoRail Simulator 3D

*Deine Eisenbahn. Deine Strecken. Deine Welt.*

Eisenbahnsimulator für Easygames: Three.js + TypeScript, als statische Dateien gebaut, läuft auf GitHub Pages (`/easygames/ricorail/`) und offline in der App. Kostenlos, keine In-App-Käufe.

- Spielen: `ricorail/index.html`
- Quelltext und Build: [`source/`](source/) – `npm ci && npm run check`
- Doku: [Architektur](docs/ARCHITEKTUR.md) · [Strecken](docs/STRECKEN.md) · [Führerstände](docs/FUEHRERSTAENDE.md) · [Spielhandbuch](docs/SPIELHANDBUCH.md) · [Lizenzen](docs/LIZENZEN.md) · [Feature-Matrix](docs/FEATURE-MATRIX.md) · [Testbericht](docs/TESTBERICHT.md) · [Release-Checkliste](docs/RELEASE-CHECKLISTE.md)

Simulation, kein offizielles Produkt der Deutschen Bahn. Reale Strecken sind vereinfacht nachgebildet. PZB, Sifa und Stellwerk sind Spielmodelle, nicht zertifiziert und nicht sicherheitsrelevant.
