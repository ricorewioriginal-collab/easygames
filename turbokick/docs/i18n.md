# Mehrsprachigkeit (i18n)

Alle Texte der Oberfläche laufen über `t('schlüssel', { platzhalter })` aus `client/src/i18n/index.ts`. Das deutsche Wörterbuch liegt in `client/src/i18n/de.ts`. Eine weitere Sprache wird mit denselben Schlüsseln als Wörterbuch ergänzt und mit `registerLocale('en', dict)` angemeldet. Fehlende Schlüssel fallen auf Deutsch zurück. Ein Test (`i18n.test.ts`) prüft, dass jeder im Code verwendete Schlüssel im deutschen Wörterbuch existiert.

Hinweis: Alle sichtbaren Texte laufen über das Wörterbuch; nur die Namen der Karosserien und Aufkleber stehen in der Render-Schicht.
