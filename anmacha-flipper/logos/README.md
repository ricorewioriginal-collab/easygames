# Tisch-Logos

Hier die Senderlogos ablegen, benannt `01.jpg`, `02.jpg` … bis `13.jpg` (auch `.jpeg` oder `.png`).

- Jedes Logo = ein eigener Tisch (Layout und Farben wechseln pro Tisch), das Logo erscheint oben auf dem Tisch
- Ohne Logos gibt es 3 Platzhalter-Tische
- Tipp: ca. 400 × 400 px, unter 200 KB, damit das Spiel schnell lädt. Transparente PNGs sind möglich, sie bekommen einen hellen Hintergrund
- Bei file:// blockiert der Browser die Bilder: Spiel über GitHub Pages oder einen lokalen Server öffnen
