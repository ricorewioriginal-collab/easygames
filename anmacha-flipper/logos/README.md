# Tisch-Logos

Es gibt **13 Tische**. Tisch *n* bekommt das Logo `NN.png` (auch `.jpg` oder `.jpeg`): `01.png` für Tisch 1 … `13.png` für Tisch 13.

- Fehlt ein Logo, zeigt der Tisch einen Platzhalter mit der Nummer
- Jeder Tisch hat ein eigenes Layout, eigene Farben und Spielfeld-Kunst, das Logo erscheint oben auf dem Tisch
- Tipp: ca. 400 × 400 px, unter 200 KB, damit das Spiel schnell lädt. Transparente PNGs sind möglich, sie bekommen einen hellen Hintergrund
- Bei file:// blockiert der Browser die Bilder: Spiel über GitHub Pages oder einen lokalen Server öffnen
- Das Titel-Logo des Spiels (`../logo.png`) liegt eine Ebene höher im Spielordner
