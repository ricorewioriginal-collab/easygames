# Mehrsprachigkeit (i18n)

Alle Texte der Oberfläche laufen über `t('schlüssel', { platzhalter })` aus `client/src/i18n/index.ts`. Das deutsche Wörterbuch liegt in `client/src/i18n/de.ts`. Eine weitere Sprache wird mit denselben Schlüsseln als Wörterbuch ergänzt und mit `registerLocale('en', dict)` angemeldet; sie erscheint dann automatisch in den Optionen. Fehlende Schlüssel fallen auf Deutsch zurück. Ein Test (`i18n.test.ts`) prüft, dass jeder im Code verwendete Schlüssel im deutschen Wörterbuch existiert.

Hinweis: Einige Bildschirme (Optionen, Anleitung, Credits, Kosmetik) und die Namen der Minispiele/Gegenstände/Ereignisse stehen noch direkt als deutsche Texte im Code oder in den Spieldaten – sie sind nicht vollständig übersetzbar.
