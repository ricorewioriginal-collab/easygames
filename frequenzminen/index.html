So geht's

Unter einigen Funkplatten stecken Störsender 📡. Decke alle anderen Platten auf, ohne einen Störsender zu erwischen. Jede offene Platte zeigt, wie viele Störsender auf den 8 Nachbarfeldern rauschen – eine leere Platte deckt ihre Nachbarn automatisch auf. Der erste Klick ist immer sicher.

  • 🚩 Peiler markieren Felder, unter denen du einen Störsender vermutest – sie schützen vor versehentlichem Aufdecken.
  • Zahl antippen: Stehen rund um eine Zahl genau so viele Peiler, deckt ein Tipp auf die Zahl alle übrigen Nachbarn auf.
  • 💡 Peilung: 3 × pro Runde deckt sie eine sichere Platte auf – kostet aber 20 Sekunden.
  • Punkte: jede freie Platte zählt, beim Sieg gibt's einen Bonus – je schneller, desto mehr. Leicht ×1, Mittel ×2, Schwer ×4.
  • 📅 Tagesrätsel: ein Feld pro Tag, für alle gleich – Ergebnis teilen und vergleichen.

Steuerung

  • Maus: Links aufdecken, Rechts Peiler setzen, Mausrad zoomt.
  • Touch: Tippen deckt auf, lange drücken setzt einen Peiler (oder 🚩 umschalten). Zwei Finger zoomen, mit einem Finger verschieben.
  • Tastatur: Pfeile/WASD bewegen den Rahmen, Leertaste/Enter aufdecken, F Peiler, H Peilung, +/− Zoom, Esc Pause.
  • Gamecontroller: Steuerkreuz/Stick bewegen, A aufdecken, X Peiler, Y Peilung, LB/RB Zoom, Start Pause.
