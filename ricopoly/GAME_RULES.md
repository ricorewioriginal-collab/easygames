# Spielregeln RicoPoly 3D

Das vollständige Regelhandbuch steht im Spiel unter **Regeln & Tutorial** (Deutsch und Englisch, Quelle: `js/i18n.js`). Hier die Kurzfassung mit den Zahlen der Regel-Engine (`js/rules.js`).

| Regel | Wert |
|---|---|
| Startgeld | 1.500 RC (einstellbar 300–10.000) |
| Über Start | 200 RC, Schnellmodus 300 RC; optional doppelt bei genauem Landen |
| Würfel | 2 × W6; Pasch = noch einmal; 3. Pasch = Gefängnis |
| Kauf | Freies Grundstück zum Listenpreis oder Versteigerung (alle aktiven Spieler, reihum, Passen scheidet aus) |
| Miete Straße | Grundmiete; volle Farbgruppe ohne Häuser doppelt; 1–4 Häuser, Hotel laut Urkunde |
| Miete Bahnhof | 25 / 50 / 100 / 200 RC |
| Miete Werk | 4 × Augenzahl, beide Werke 10 × |
| Bauen | Nur mit voller Gruppe, keine Hypothek in der Gruppe, gleichmäßig, im eigenen Zug oder beim Begleichen von Schulden; Bank: 32 Häuser, 12 Hotels |
| Verkaufen | Halber Baupreis, gleichmäßig; Hotel wird zu 4 Häusern, falls vorrätig |
| Hypothek | Halber Kaufpreis, keine Miete; Ablösen + 10 % Zinsen; im Handel erhaltene belastete Grundstücke kosten sofort 10 % |
| Gefängnis | Pasch, 50 RC Kaution oder Freikarte; nach 3 Fehlversuchen (Schnell: 2) Pflichtzahlung; Miete wird weiter kassiert |
| Karten | Je Welt 20 Ereignis- und 20 Gemeinschaftskarten, gemischt, Freikarten behält man |
| Frei Parken | Ohne Wirkung; mit Topf-Regel gibt es alle Steuern, Strafen und Kautionen |
| Handel | Grundstücke, Geld, Freikarten; nicht bei Gebäuden in der Gruppe; Annehmen, Ablehnen, Gegenangebot |
| Bankrott | Erst liquidieren; an Spieler: alles geht an den Gläubiger; an die Bank: Grundstücke werden wieder frei |
| Ende | Klassisch: letzter Spieler; mit Runden- oder Zeitlimit: größtes Vermögen (Geld + Grundstückswert + Gebäude − Hypotheken) |
